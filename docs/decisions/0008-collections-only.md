# 0008 — Collections only, no ordered reading lists

**Status**: accepted

**Decision**: Users have private, unordered collections with sorting (date added, title, last read,
latest update) and filters (reading status, type, tags). Ordered, drag-and-drop reading lists were
dropped.

**Why**: Continue Reading already answers "what am I reading now", and an unordered collection with
sorting covers the rest. Reading lists duplicated collections with extra UI work.
