# 0009 — One language per series; vertical reader only

**Status**: accepted

**Decision**: Each media has exactly one language. When a better-language edition arrives, it
replaces the old one (edit language, replace chapters). The reader is vertical scroll only; there
is no reading-direction field.

**Why**: Matches how the owner collects (English when available, original language until then).
A single reading mode keeps the reader simple and polished.
