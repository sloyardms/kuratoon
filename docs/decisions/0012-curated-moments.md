# 0012 — Moments are curated and public, with optional user submissions

**Status**: accepted

**Decision**: Moments are cropped chapter highlights with a required title, visible to all users,
used to find notable scenes from the chapter list. Admins create them (auto-approved). An admin
setting (default off) lets users submit moments, which go to a review queue (PENDING → APPROVED /
REJECTED). Rejected moments are deleted.

**Why**: Moments are a shared index of important scenes, not personal screenshots. Submissions
make creating them faster without losing curation.
