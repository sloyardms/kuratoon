# 01 — Data model

PostgreSQL with the `pg_trgm` and `citext` extensions. All schema changes via Flyway.
All timestamps are `timestamptz`. Primary keys are UUIDv7 (`uuid`) unless noted; UUIDs are
generated by the application. No soft deletes.

Column lists below are the contract. Index lists are the minimum; add more if a query needs it
and mention it in the phase report.

## Conventions

- `created_at` defaults to `now()`. `updated_at` is maintained by the application.
- Enums are stored as `text` with a `CHECK` constraint (easier to migrate than Postgres enums).
- Denormalized counters (marked **denorm**) are updated in the same transaction as the change that
  affects them.

Required by the service layer (not expressible as constraints): at least one creator with role

### `media_title` (alternative titles)
id, media_id (FK cascade), title (text NOT NULL), language (text NULL). UNIQUE(media_id, title).
GIN trigram index on `title`. Title search matches `media.title` OR any `media_title.title`.

### `creator`
id, name (text NOT NULL), normalized_name (text UNIQUE NOT NULL: lowercased, trimmed, collapsed
whitespace), created_at. GIN trigram on `name`.

### `media_creator`
(media_id FK cascade, creator_id FK, role) PK. role: `AUTHOR` \| `ARTIST`.
The same creator may hold both roles. No other roles exist.

### `tag`
id, name (text NOT NULL), slug (text NOT NULL), kind (`GENRE` \| `LIBRARY`), created_at.
UNIQUE(kind, slug). GENRE tags come from scraping or admin; LIBRARY tags are admin-only
(e.g. "hq", "rescan needed"). Displayed separately.

### `media_tag` (media_id FK cascade, tag_id FK cascade) PK. Index on (tag_id, media_id).

### `parody`
id, name (text NOT NULL), normalized_name UNIQUE, created_at.

| Column | Type | Notes |
|---|---|---|
| id | uuid PK | |

## Feeds and queries (for reference)

- **Latest updates**: media ordered by `latest_chapter_added_at DESC`, card shows the range of
  chapters added in the most recent import batch (from `chapter.created_at` within that media).
- **New media**: `media.created_at DESC`.
- **Most read (30 days)**: count of `read_event` per media in the last 30 days.
- **Browse filters**: type, tags (include/exclude), status, creator, parody, character, language,
  minimum chapters (`chapter_count`), adult, user intent/progress, title text (trigram).
  Structured filters use indexed `EXISTS` subqueries.
- **User visibility filters** (adult mode, hidden types, excluded tags) apply to every feed,
  browse and search result for that user.
- Feeds use keyset pagination on (sort key, id).
